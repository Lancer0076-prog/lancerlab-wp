# LancerLab WordPress (`lancerlab-wp`)

Код кастомного оформления, конфигурации и дорожная карта личного сайта-визитки и инженерного блога **LancerLab** (`http://lancer0076.keenetic.pro:8081/`).

## Состав
- `mu-plugins/lancerlab-styles.php` — кастомный CSS-слой поверх темы Twenty Twenty-Five (адаптивная сетка `1120px`, Hero-блок, полоса метрик, карточки проектов, чипы стека, стили для кода и футер).
- `SITE_ROADMAP.md` — план развития сайта, перехода на HTTPS и интеграции с GitHub.
